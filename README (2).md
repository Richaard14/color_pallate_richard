# Color Palette Extractor — Versi Awal

## File
- `index.html` — struktur halaman
- `style.css` — tampilan gelap versi awal
- `script.js` — logika ekstraksi palet warna menggunakan Color Thief

## Menjalankan
Buka `index.html` di browser. Koneksi internet diperlukan agar library Color Thief dari CDN dapat dimuat.

## Deploy ke GitHub Pages
Upload `index.html`, `style.css`, dan `script.js` ke root repository. Buka Settings → Pages, pilih Deploy from a branch, branch `main`, folder `/(root)`, lalu Save.
